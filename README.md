## Project Description

This project is a console-based Student Record and Result
Management System developed using the C programming language.

It helps maintain student academic records and calculate
their CGPA.

It also includes an AI-Assisted Academic Advisor that provides
academic recommendations based on student CGPA.

## Features

1. Add student details
2. Search student records using SAP ID
3. Display all student records
4. Calculate individual CGPA
5. Calculate year-wise average CGPA
6. Delete student records
7. Sort students by SAP ID
8. Sort students alphabetically by name
9. AI-Assisted Academic Advisor
10. Permanent data storage using file handling

## Technologies Used

- C Programming Language
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- File Handling

## How to Run

Compile:

gcc YOUR_SAP_ID.c -o student

Run on Windows:

student.exe

## Academic Advisor Categories

- 9.0–10.0: Excellent Performance
- 7.5–8.99: Good Performance
- 6.0–7.49: Needs Improvement
- Below 6.0: Requires Immediate Attention

## Data Storage

Student records are stored in student_records.dat.
